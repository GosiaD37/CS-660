## About This Repository

This repository is my portfolio for CS 660, Advanced Programming Language Theory. In this course, I explored how programming languages handle types, scope, memory, and errors. I also studied how those design choices affect software reliability, performance, and maintenance.

## Selected Projects

| Project | What I Worked On |
| --- | --- |
| Legacy System Modernization | Developed a modernization proposal and used pseudocode to show how the proposed system would handle key operations. |
| Domain-Specific Language Design | Designed a small language for converting nightly CSV files into structured JSON. I outlined its syntax and mapped how it would validate input and produce output. |
| Java vs. Go for a Fintech Backend | Compared Java and Go for a payment processing service, considering transaction reliability, concurrency, runtime behavior, and long-term maintenance. |
| Python Sorting Benchmarks | Measured execution time and peak memory usage for quicksort, merge sort, and heapsort, then evaluated the results against predefined targets. |
| Expression Parsing | Worked with grammar rules and an abstract syntax tree to show how an interpreter evaluates expressions like `2 + 3 * 4` in the correct order. |

## Topics Covered

- Static and dynamic typing, variable binding, and scope
- Imperative, object-oriented, and functional programming
- Exception handling in Java and error handling with `Maybe` and `Either` in Haskell
- Memory management and garbage collection
- Grammars, parsing, and abstract syntax trees
- Runtime performance and language selection

## Takeaway

This course taught me to explain why a language fits a project. For a payment service, I focused on transaction support and maintainability. For a nightly data conversion task, I designed a small language with clear rules for input validation. Both projects helped me connect programming language theory to practical software engineering decisions.
